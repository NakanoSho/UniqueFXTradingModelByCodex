# 基本設計書：安定コア＋攻撃サテライト型 FX モデル（MVP）

## 0. 目的と前提
- 目的: 独立後に最短で「壊れない」FXモデルを立ち上げ、事業拡大可能な運用基盤を構築する。
- 対象: G10中心（初期は流動性・コスト重視）。
- 時間軸: 日次〜4時間足（後に短期追加）。
- 目標: 年率ボラ 8–12%、最大DD 10–15%以内、月次損失上限 4–6%。
- 回転: 低〜中。TCAが整うまで高回転禁止。
- 攻撃的運用: 通常リスクの 1.5〜2.5倍を条件付きで許可。
- 収益形態: ①自己運用 → ②運用受託/助言 → ③シグナル提供。
- 信頼性: 監査可能なログ、再現可能なバックテスト、日次レポート。
- 法務/規制: 最初の2週間で専門家レビュー前提（必須）。

## 1. 全体アーキテクチャ（MVP）

### 1.1 モジュール構成
- data_ingest: データ取得（FXスポット/フォワード、OIS/短期金利、主要マクロ、ボラ指標）。
- data_normalize: タイムゾーン/欠損/休日調整、通貨ペア整合。
- feature_engineering: トレンド/キャリー/バリュー指標、ボラ、リスクオフ指標。
- signal_core: コア3本柱（トレンド/キャリー/バリュー）。
- signal_satellite: 攻撃サテライト（ブレイクアウト、短期リバーサル、イベント回避/追随）。
- regime_overlay: リスクオフ判定、サテライトON/OFF、キャリー縮小。
- portfolio_construction: ボラターゲティング、リスク配分、制約適用。
- risk_control: DDベース減速、kill-switch。
- backtest_engine: 再現可能なバックテスト、ウォークフォワード。
- execution_sim: スリッページ、スプレッド、ロール挙動をシミュレーション。
- reporting: 日次/月次レポート生成。
- audit_log: 監査可能なログと再現性メタデータ。

### 1.2 データパイプライン
1) 取得 → 2) 正規化 → 3) 保存 → 4) 特徴量生成 → 5) シグナル生成 → 6) ポートフォリオ構築 → 7) バックテスト/配信 → 8) 監視/レポート。

## 2. 戦略設計

### 2.1 コア（常時稼働、80–90%）
1) トレンド（Time-series momentum）
- 期間: 例 5/20/60日（設定で変更可）。
- 合成: 期間別シグナルの平均/重み付け。

2) キャリー（金利差＋ロールダウン）
- 低ボラ環境で優先。
- リスクオフ時は縮小。

3) バリュー（平均回帰）
- PPP/REERなど週次〜月次の緩い指標。
- 反応速度は低速（過剰フィット回避）。

### 2.2 サテライト（条件付き稼働、10–20%）
候補（順番推奨）:
1) ブレイクアウト/ボラ拡大
2) 短期リバーサル（コスト厳密反映）
3) イベント回避/追随

サテライト稼働条件（AND）:
- トレンドとキャリーが同方向で一致。
- 実現ボラが中低水準。
- リスクオフ指標が悪化していない。

### 2.3 レジーム・オーバーレイ
- リスクオフ指標（株ボラ、クレジット、金利急変、実現ボラ）を監視。
- リスクオフ時:
  - キャリー縮小。
  - サテライト停止。
  - トレンドは継続（防御的役割）。

## 3. ポートフォリオ/リスク設計

### 3.1 ポートフォリオ構築
- 目標ボラ一定（vol targeting）。
- 相関考慮: 簡易リスクパリティ/縮小共分散。
- 制約:
  - 通貨ごと上限。
  - 地域ごと上限。
  - USD偏り上限。
  - ネット/グロス上限。

### 3.2 損失制御
- 日次/週次DDに応じて段階的にリスク縮小。
  - 例: DD 5%で-30%、DD 8%で-60%。
- kill-switch: ルール化された停止条件。

### 3.3 攻撃リスク枠
- 通常リスクの 1.5〜2.5倍まで条件付き許可。
- DD条件で即時縮小。

## 4. 監視・ログ・レポーティング

### 4.1 監視

### 4.2 ログ

## 10. 数値仕様の固定（収益・リスク・制約）

### 10.1 収益目標の逆算（ネット年利10%）
- ネット年利（幾何平均）目標: +10.0%
- 月次換算: (1.10)^(1/12) - 1 ≈ +0.80%/月
- コスト予算（上限）: 年2.0%
  - スプレッド、スリッページ、リバランスコスト、ロール実務影響を含めた実現コスト
- グロス期待リターン要求: +12.0%/年（=10%+2%）

### 10.2 リスク目標（年利10%達成の固定値）
#### 10.2.1 ターゲット・ボラと必要シャープ
- 年率ボラ目標（ポートフォリオ）: 10.0%（通常運転時）
- 要求シャープ（ネット）: SR_net = 10% / 10% = 1.0
- 要求シャープ（グロス）: SR_gross = 12% / 10% = 1.2
- 結論: 年率ボラ10%で年利10%を狙うなら、ネットSharpe 1.0（グロス1.2）を要件として固定

#### 10.2.2 ドローダウンと損失上限（ハード制約）
- 最大DD（ハード）: 15.0%（到達で全戦略停止・ポジション解消、再稼働はレビュー後）
- 最大DD（ソフト目標）: 12.0%以内
- 月次損失上限（ハード）: -6.0%（到達で当月新規停止、リスク0〜25%へ）
- 週次損失上限（ハード）: -3.5%
- 日次損失上限（ハード）: -2.0%
- 参考: 年率ボラ10%のとき、日次σ≈0.63%、月次σ≈2.9%、月次-6%は約2.1σ相当

#### 10.2.3 VaR/ES（運用監視の固定値）
- 1日99% VaR 上限: 1.5%（超過で当日新規停止＋翌営業日リスク半減）
- 1日97.5% ES 上限: 2.0%

### 10.3 対象・時間軸（固定）
#### 10.3.1 対象（G10中心・初期ユニバース固定）
- G10通貨の主要ペア（USD絡み＋主要クロス）から開始
- 初期運用対象数: 8〜14ペア
- 除外: 流動性が落ちる時間帯、祝日薄商い、異常スプレッド時は新規禁止

#### 10.3.2 時間軸（v1.0固定）
- シグナル: 日次＋4時間（併用可）
- リバランス頻度
  - Core: 日次1回まで（原則）
  - Satellite: 4時間足更新ごとに判定（稼働条件満たすときのみ）

### 10.4 取引回転とコスト（上限）
#### 10.4.1 取引回転（固定上限）
- 年間ターンオーバー上限（総約定代金/AUM）: 600%/年
  - Core: <= 400%/年
  - Satellite: <= 200%/年
- 目的: コスト予算（年2%）を割らないこと
- 実測コストが想定より大きい場合は、ターンオーバー上限を自動的に引き下げ

#### 10.4.2 コスト上限の運用ルール
- 月次の実現コスト（bps）を監視し、年率換算で2.0%超の見込みで
  - 1) Satellite停止
  - 2) Coreのリバランス頻度低下
  - 3) ポジション上限縮小

### 10.5 ポジション制約（固定ルール）
- 通貨別リスク寄与上限: 総リスクの25%
- 単一ペアのリスク寄与上限: 総リスクの15%
- ネットUSDエクスポージャ上限: グロスの±35%
- グロスレバレッジ（目安上限）: 6倍（上限超過シグナルは強制クリップ）
- ギャップ/イベント: 重要イベント前後で新規禁止帯を設定（v1.0は回避優先）

### 10.6 "攻撃的"の定義（数値固定）
#### 10.6.1 リスク予算の二層化
- 通常運転（Base）: 年率ボラ10%
- 攻撃モード（Aggressive）: 通常の1.8倍まで（年率ボラ上限18%）
- リスク配分: Core 85% / Satellite 15%（リスク予算ベース）

#### 10.6.2 攻撃モード稼働条件（ゲート）
攻撃モードは全条件OKでのみON:
1) リスクオフ指標が悪化していない
2) Core主要シグナルが同方向で整合
3) 直近DD <= 4%
4) 当月損益 > -2%

#### 10.6.3 DDに応じた強制デリスク
- DD 4%到達: 総リスク -25%
- DD 6%到達: 総リスク -50%、Satellite停止
- DD 10%到達: 総リスク -75%
- DD 12%到達: 新規停止（既存縮小のみ）
- DD 15%到達: 全停止・フラット化

### 10.7 合格基準（バックテスト／紙運用）
- ネット年利 >= 10%（コスト控除後）
- 年率ボラ 10% ± 2%（通常時）
- Sharpe（ネット） >= 1.0（0.8未満は仕様不達）
- 最大DD <= 15%（目標 <= 12%）
- 月次損失 -6%超の頻度が過大でない
- コスト年率 <= 2.0%
- レジーム別（リスクオフ期間）の損失が許容内

## 11. スリーブ割当・ゲート・合成ルール（固定仕様）

### 11.1 モード定義（3段階）
- M0（通常）: 目標年率ボラ 10%
- M1（攻撃L1）: 目標年率ボラ 14%（=1.4x）
- M2（攻撃L2）: 目標年率ボラ 18%（=1.8x、上限）
- 攻撃の定義: 総リスク（目標ボラ）を最大1.8倍まで引上げ可能
- SatelliteはM1/M2ゲート成立時のみ付与（M0は0固定）

### 11.2 スリーブ仕様（確定）
- Trend（TS-Mom）
  - リスク予算（M0/M1/M2）: 45 / 50 / 55
  - リスク寄与上限: <= 55%
  - ターンオーバー上限: <= 180%/年
  - リバランス: 日次
  - 主ゲート: 流動性OK、SpreadStress <= 1.5（基本ON）
- Carry（Rate diff）
  - リスク予算（M0/M1/M2）: 25 / 25 / 25
  - リスク寄与上限: <= 30%
  - ターンオーバー上限: <= 140%/年
  - リバランス: 日次（変更は平滑化）
  - 主ゲート: Risk-Offで縮小/停止、キャリークラッシュ停止
- Value（Mean reversion）
  - リスク予算（M0/M1/M2）: 15 / 15 / 15
  - リスク寄与上限: <= 20%
  - ターンオーバー上限: <= 80%/年
  - リバランス: 日次
  - 主ゲート: 強トレンド局面は停止、高ボラで縮小
- Satellite（攻撃）
  - リスク予算（M0/M1/M2）: 0 / 10 / 15
  - リスク寄与上限: <= 15%
  - ターンオーバー上限: <= 200%/年
  - リバランス: 4時間
  - 主ゲート: M1/M2条件成立時のみON

- Core合計（Trend+Carry+Value）: M0時 85%固定。攻撃時はTrend側へ寄せ最大55%まで。
- 取引回転合計上限: Core <= 400%/年、Satellite <= 200%/年（総 <= 600%/年）

### 11.3 共通の市場ストレス指標（内部計算）
- FXVol20: 対象ペア20日実現ボラ（年率換算）の中央値
- VolJump: FXVol5 / FXVol60（中央値）
- SpreadStress: 現行スプレッド / 60日中央値（ペアごと）→その中央値

Risk-Offフラグ（いずれか）:
- FXVol20 > 12%
- VolJump > 1.5
- SpreadStress > 1.5

Risk-Onフラグ（全て）:
- FXVol20 < 10%
- VolJump < 1.2
- SpreadStress < 1.2

### 11.4 スリーブ別ゲート（固定）
- Trend
  - ON条件: 流動性OK かつ SpreadStress <= 1.5
  - 信号閾値: 60日モメンタムZ |Z| >= 0.5 未満は0（フラット）
  - 例外停止: データ異常、SpreadStress > 1.5、約定品質異常
- Carry
  - Risk-On: リスク予算100%
  - Risk-Off: リスク予算0%（当日リバランスで段階的に0へ）
  - キャリークラッシュ停止: 5営業日累積損益 -2.5%下回りで10営業日停止
- Value
  - ON条件（レンジ優位）: 60日モメンタムZ |Z| <= 1.0 のときのみ許可
  - 縮小条件: FXVol20 > 12%で50%、FXVol20 > 14%で停止
- Satellite
  - M1起動条件（全て）:
    - Risk-Onフラグ=ON
    - 直近DD <= 4%
    - 当月損益 > -2%
    - TrendとCarryの方向整合（同方向エッジが過半のペアで一致）
  - M2追加条件（全て）:
    - 直近DD <= 2%
    - SpreadStress < 1.1
    - 直近20取引の実測スリッページ <= 想定比1.2倍
  - 停止条件（共通）: Risk-Off=ON、当日 -2% 到達、週次 -3.5% 到達で即時0%

### 11.5 ポートフォリオ合成ルール（固定）
#### 11.5.1 合成手順
1) ユニバースフィルタ（流動性OK／スプレッド正常）
2) 各スリーブで生シグナル → スコア化（方向＋強度）
3) スリーブ内配分（相関調整込み）でペア別ウェイト生成
4) スリーブ別vol targeting（スリーブ目標リスクへスケール）
5) スリーブ合成（リスク予算に従い線形合成）
6) クリップ（単一ペア・通貨・レバ・VaR・DD）
7) 総合vol targeting（M0/M1/M2目標ボラへ最終スケール）
8) ターンオーバー制御（平滑化）→ 執行

#### 11.5.2 スリーブ内の相関調整
- 日次リターン共分散 Σ: 60日EWMA（λ=0.94目安）+ shrinkage
- 符号: sign(score)
- 大きさ: |score|比例（下限・上限あり）
- 相関調整: リスクパリティ近似で偏りを緩和

#### 11.5.3 vol targeting
- 予測ボラ: スリーブ/ポートフォリオの日次リターンから推定
- スケール係数: k = 目標年率ボラ / 予測年率ボラ
- 上限: k <= 1.5（スリーブ内、総合も同様）

#### 11.5.4 クリップ優先順位
1) 損失・停止系（最優先）
   - 日次 -2% / 週次 -3.5% / 月次 -6% / DD -15% ルール
2) 総グロスレバ上限
   - M0: 6.0x、M1: 7.0x、M2: 8.0x（ハード）
3) 単一ペアのリスク寄与 <= 15%
4) 通貨別リスク寄与 <= 25%
5) スリーブ別リスク寄与上限（Trend<=55%、Carry<=30%、Value<=20%、Satellite<=15%）
6) ネットUSDエクスポージャ: グロスの ±35%
7) 単一ペアノーショナル上限
   - M0 <= 1.5x NAV、M1/M2 <= 2.0x NAV
- クリップ違反が残る限り、目標ボラ未達を許容（DD制約優先）

#### 11.5.5 ターンオーバー制御
- 平滑化: w_t = (1-ρ) w_{t-1} + ρ w*
- ρはターンオーバー上限を満たすよう自動調整
- それでも上限超なら、シグナル強い上位から更新し弱い更新は繰延

### 11.6 ゲート停止時のリスク再配分（固定）
- Carry停止（Risk-Off）:
  - Trendへ +10（最大55まで）
  - Valueへ +5（ゲートON時のみ、最大20まで）
  - 残りはキャッシュ
- Value停止:
  - Trendへ +10（最大55まで）
  - 残りはキャッシュ
- Satellite停止（M0またはゲート不成立）:
  - 0固定（Coreへは自動移転しない）

## 12. スコア定義・初期パラメータ・TCA前段（固定仕様）

### 12.1 共通定義（記号・関数）
- 価格: 通貨ペア i の終値（またはミッド）を S_{i,t}
- 対数リターン: r_{i,t} = ln(S_{i,t} / S_{i,t-1})
- EWMA分散:
  - σ^2_{i,t} = λ σ^2_{i,t-1} + (1-λ) r_{i,t}^2
  - 日次: λ=0.94、4時間足: λ=0.97（固定）
- Z化（ローリング）: z(x_t;L) = (x_t - μ_{t,L}) / s_{t,L}
  - 日次: L=252（1年）または756（3年）を用途で固定
- ウィンザー: winsor(z,3) = min(3, max(-3, z))
- スコアクリップ: clip01(x) = tanh(x/2)
- 最終スコア統一:
  - Score_{i,t} = clip01(winsor(RawScore_{i,t}, 3))

### 12.2 Trend（TS-Momentum）スコア（固定）
#### 12.2.1 RawScore
- 期間（固定）: 20/60/120営業日
- 重み（固定）: 0.5 / 0.3 / 0.2
- 短期ボラ: σ^{20}_{i,t}（日次EWMAで20日相当）
- 各期間のトレンド量:
  - T_{i,t}(h) = ln(S_{i,t}/S_{i,t-h}) / (σ^{20}_{i,t} sqrt(h))
- 合成:
  - RawTrend_{i,t} = 0.5 T(20) + 0.3 T(60) + 0.2 T(120)

#### 12.2.2 参入閾値（固定）
- 取引ON: |RawTrend_{i,t}| >= 0.5
- それ以外: 0（フラット）

### 12.3 Carry スコア（固定）
#### 12.3.1 Raw Carry
- 前提: 1Mフォワード F^{1M}_{i,t} が取得可能
- Carry年率化:
  - CarryAnn_{i,t} = ln(F^{1M}_{i,t} / S_{i,t}) * (365 / D)
  - Dは残存日数（概ね30）
- 符号規約: ペア A/B で Score>0 は Aロング（=ペアロング）

#### 12.3.2 Cross/TimeハイブリッドZ（固定）
- クロスセクションZ:
  - z^{cs}_{i,t} = (CarryAnn_{i,t} - mean_t) / std_t
- タイムシリーズZ:
  - z^{ts}_{i,t} = z(CarryAnn_{i,t}; 252)
- 合成:
  - RawCarry_{i,t} = 0.6 z^{cs}_{i,t} + 0.4 z^{ts}_{i,t}

#### 12.3.3 ボラでの滑らかな縮小（固定）
- FXVol20: ユニバース20日実現ボラ中央値（年率）
- g_vol = clip[0,1](1 - max(0, FXVol20-10)/4)
- RawCarry_{i,t} <- g_vol * RawCarry_{i,t}

#### 12.3.4 参入閾値（固定）
- 取引ON: |RawCarry_{i,t}| >= 0.3
- Risk-Offフラグ=ONの日はCarryスリーブ全体で0

### 12.4 Value（平均回帰）スコア（固定）
#### 12.4.1 価値の錨（v1.0固定）
- v1.0はテクニカル価値で固定
- 3年レンジ自己平均:
  - m_{i,t} = mean(ln S_{i,·}; 756)
  - s_{i,t} = std(ln S_{i,·}; 756)
- z^{val}_{i,t} = (ln S_{i,t} - m_{i,t}) / s_{i,t}
- RawValue_{i,t} = - z^{val}_{i,t}

#### 12.4.2 参入閾値・強トレンド停止（固定）
- 取引ON: |z^{val}_{i,t}| >= 0.7
- 強トレンド停止: |T_{i,t}(60)| > 1.0 のペアはValue=0
- 高ボラ停止: FXVol20 > 14% でValueスリーブ全体0

### 12.5 Satellite（4時間足・ブレイクアウト＋ボラ拡大）スコア（固定）
- SatelliteはM1/M2ゲート通過時のみ配分

#### 12.5.1 4Hブレイクアウト（Donchian×ATR）
- 4H終値 C_{i,t}
- Donchian:
  - H^{20}_{i,t} = max(C_{i,t-19:t}), L^{20}_{i,t} = min(C_{i,t-19:t})
  - M = (H+L)/2
- ATR: ATR^{20}
- RawBreak_{i,t} = (C_{i,t} - M^{20}_{i,t}) / ATR^{20}_{i,t}

#### 12.5.2 ボラ拡大の追い風（4H）
- VR_{i,t} = σ^{8}_{i,t} / σ^{60}_{i,t}
- z^{vr}_{i,t} = z(VR_{i,t}; 120)

#### 12.5.3 合成・整合・閾値（固定）
- RawSat_{i,t} = 0.7 RawBreak_{i,t} + 0.3 z^{vr}_{i,t} * sign(RawBreak_{i,t})
- 日次Trend整合: sign(RawSat_{i,t}) = sign(RawTrend_{i,t}) を満たさない場合0
- 参入閾値: |RawSat_{i,t}| >= 1.0

#### 12.5.4 退出（固定）
- |RawSat_{i,t}| < 0.3 で退出
- 最大15本（約2.5日）経過で強制退出

### 12.6 共分散・相関調整（固定）
#### 12.6.1 共分散推定（固定）
- 日次: 60日EWMA（λ=0.94）
- 縮小:
  - Σ^{shr} = (1-δ) Σ + δ diag(Σ)
  - 日次: δ=0.30
  - 4H（Satellite）: δ=0.40

#### 12.6.2 スコア→生ポジション（固定）
- p_{i,t} = Score_{i,t} / σ_{i,t}
- σは日次なら20日EWMA、4Hなら60本EWMA

#### 12.6.3 相関調整（固定アルゴリズム）
- 反復3回で打切り
- 手順:
  1) w <- p
  2) Σ^{shr}でリスク寄与 RC_i を計算
  3) RC_iが15%超のペアは w_i <- w_i * 0.8
  4) スリーブ目標ボラに再スケール

### 12.7 vol targeting（固定）
- スリーブ目標ボラ（M0基準の内部値）
  - Trend: 総リスク予算の45%
  - Carry: 25%
  - Value: 15%
  - Satellite: M1で10%、M2で15%（ゲート通過時のみ）
- 予測年率ボラ:
  - σ^slv = sqrt(w^T Σ^{shr} w) * sqrt(252)
- スケール:
  - w <- w * min(1.5, σ^target_slv / σ^slv)
- 合成後も全体で同様にスケール
- 目標ボラ: M0=10% / M1=14% / M2=18%（上限1.5固定）

### 12.8 コスト/スリッページ推定（TCA前段、固定）
#### 12.8.1 入力（取得必須）
- mid、bid/ask
- Quoted spread（bps）:
  - Spread_bps = (ask - bid) / mid * 10^4
- 実行用短期ボラ（bps）:
  - Core: 直近60分の1分足
  - Satellite: 直近15分の1分足
  - σ^{exec}_{bps} を算出
- 取引量proxy: |Δw_i|
- 流動性Tier（固定）:
  - Tier A: EURUSD, USDJPY, GBPUSD, AUDUSD, USDCAD, USDCHF
  - Tier B: その他G10主要クロス
- 参照流動性:
  - Q^{ref}_i = k^{tier} * NAV
  - Tier A: k^{tier}=50
  - Tier B: k^{tier}=20

#### 12.8.2 期待コストモデル（固定）
- α_spr=1.2、α_imp=1.0
- 実行ウィンドウ: Core 60分、Sat 15分
- 参加率proxy:
  - ρ_i = |Δw_i| * NAV / Q^{ref}_i
- 期待インパクト:
  - Impact_bps = α_imp * σ^{exec}_{bps} * sqrt(ρ_i)
- 期待コスト（ショートフォール近似）:
  - ExpCost_bps = 0.5 * α_spr * Spread_bps + Impact_bps + 0.1

#### 12.8.3 コスト制約（固定）
- Core許可: ExpCost_bps <= 2.0
- Satellite許可: ExpCost_bps <= 3.0
- SpreadStress > 1.5 のペアは新規禁止

#### 12.8.4 コストをスコアに反映（固定）
- RawAdj = RawScore - γ * ExpCost_bps
- γ（固定）: Core 0.15、Satellite 0.20
- 参入閾値はRawAdjに対して適用

### 12.9 実測TCA（監視、固定）
- RealCost_bps = sign(q) * (Fill - mid_decision) / mid_decision * 10^4
- 20取引移動平均で
  - mean(RealCost_bps) > 1.2 * mean(ExpCost_bps) のスリーブは
    - 平滑化係数 ρ を20%引下げ
    - SatelliteのM2ゲート停止（M1まで）
