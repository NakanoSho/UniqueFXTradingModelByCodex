# Clean Room Policy

## 1. Purpose
This policy ensures all research, code, data, and operational know-how are built from scratch and are verifiably independent from any prior employer or third-party confidential materials.

## 2. Prohibited Materials
The following are strictly prohibited from being used, referenced, or replicated:
- Source code, model specifications, research notes, datasets, client information
- Pricing/terms, execution tactics, internal heuristics, or operational procedures
- Any parameters, thresholds, weights, or exception-handling logic derived from prior employment

## 3. Allowed Sources
Only the following sources are permitted:
- Public information
- Self-generated experiments and analysis
- Properly licensed datasets with documented provenance

## 4. Implementation Rules
- Do not attempt to recreate prior models or parameter values.
- All experiments must be logged with provenance, code commit, and data snapshot IDs.
- All design decisions must be recorded in `DECISIONS.md`.

## 5. Enforcement
Any violation requires immediate halt of work and review by the project owner.
